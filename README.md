# WARM MEDIA — الملفات المفصولة

## الملفات
- `index.html` الصفحة العامة.
- `admin.html` لوحة الإدارة.
- `css/style.css` تنسيقات الموقع العام.
- `css/admin.css` تنسيقات لوحة الإدارة.
- `js/app.js` JavaScript الموقع العام.
- `js/admin.js` JavaScript لوحة الإدارة.
- `supabase.sql` جداول قاعدة بيانات Supabase وسياسات الحماية.

## التشغيل
ارفع المجلد كما هو إلى الاستضافة، مع الحفاظ على أسماء المجلدات والملفات.
افتح `index.html` للموقع و`admin.html` للوحة الإدارة.

## قاعدة البيانات
1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor والصق محتوى `supabase.sql` وشغّله.
3. أنشئ حساب دخول إداريًا من Supabase Auth، ثم أضف `user_id` الخاص به إلى جدول `wm_admins`.

**مهم:** فصل الملفات تم مع الحفاظ على الواجهة والأقسام والسلوك الأصلي. النسخة الحالية ما زالت تستخدم `localStorage` مثل الملفات الأصلية؛ ملف SQL ينشئ قاعدة البيانات الآمنة كبنية جاهزة، لكنه لا يعني أن الواجهة أصبحت متصلة بها تلقائيًا. يلزم ربط Supabase بالمفاتيح الخاصة بالمشروع وإكمال تسجيل دخول الإدارة وإرسال التعليقات عبر RPC قبل اعتبارها نسخة متصلة فعليًا. لا تضع `service_role` key داخل ملفات JavaScript أو داخل الاستضافة العامة.
